Type a sentence or drop a photo. Get a video of it being drawn.

inkline is a Claude skill. It turns a prompt, a portrait or an SVG into a hand-drawn video: marker, pencil or chalk in frame, stroke by stroke, then a colour wash. Rendered on your machine from HTML and JavaScript.

> /plugin marketplace add SunFloat/inkline

Then /plugin install inkline@inkline and ask: draw my photo on a whiteboard

Ask for a style. Or invent one.

Say "just do it" and inkline picks for you. Want a say? Claude asks a short round of questions, and a custom look is saved as a style you can reuse.

A drawing, rendered like a film.

The video is an HTML page with a canvas whose every frame is a pure function of time. Headless Chrome seeks it frame by frame; ffmpeg stitches the frames and a synthesised pencil track.

In
A prompt, a photo (PNG, JPG, WebP, AVIF), an SVG, or a URL.
Out
MP4 or WebM in 1080p or any size you set, a poster PNG and an optional GIF. 9:16, 4:5, 1:1 and 16:9.
Faces first
On macOS and Windows, Chrome's face detection makes the pencil start at the eyes and draw the face finer.
Deterministic
Same input, style and seed give the same frames. Pages render in parallel and are joined losslessly.
Sound
Pencil, pen, marker or chalk, synthesised from the speed of every stroke. No audio files.
Local
No server, no account, no upload. Node 18 and a Chrome you already have.

Put it on your wall.

Pick the way you install skills. On first use inkline sets up its render engine by itself.

Claude Code plugin

Recommended. Updates with the plugin.

/plugin marketplace add SunFloat/inkline
/plugin install inkline@inkline

Skills CLI

Works with Claude Code and other agents that read skills.

npx skills add SunFloat/inkline

By hand

Copy the skill folder into your skills directory.

git clone https://github.com/SunFloat/inkline
cp -r inkline/skills/inkline ~/.claude/skills/
